记一下，我做如下调整，你接下来就把这个当ACNT的现在架构，不多不少，有且仅有如下架构设计：
readin：eye，ear，readout：hand，speak，goodness，route；core：block。
对于eye，采用1080p截图经adapter输入对应block，同时强制激活一次对应block；
对于ear，采用原始音频经过adapter输入对应block；
对于hand，是对应block的输出，经adapter转化为键盘鼠标的directinput；
对于speak，是对应block的输出，经adapter转化为模拟仿生发声器官的参数（约30维）；
对于goodness，是对应block的输出经adapter转化为一维好度值（0～1）；
对于route，是对应block的输出经adapter转化为总block上限数维的01block激活与休眠控制；
以上的adapter皆为神经网络，训练时其参数与block参数一样采用Local Plasticity Dynamics（局部塑性动力学）；正式ACNT不运行e-prop；
每个readin和readout都对应一个且仅对应一个不同block，readin与readin，readout与readout，read in与readout对应不同block；
每个block B_i有如下状态：
bool active：是否激活；
int neure size of B_i：B_i内有的神经元数量
int ticktime(ms):B_i的时间观感参数调整；
int hold_tick：block内选取最新预激活历史的条数；
vector<FP32>z(neure size of B_i)：这是activation，或者说block的输出状态；
vector<FP32>a(neure size of B_i)：这是preactivation，预激活；
vector<FP32>o(2*neure size of B_i)：这是readin adapter 的输出，仅与readin_adapter对应的block有；
queue<vector<FP32> >A(hold_tick)(neure size of B_i)：这里最新hold_tick条存预激活历史；
queue<int>At(hold_tick)：对应A历史的时间t（ms）；
vector<vector<FP32> >W[number of total blocks](2*neure size of B_i)(neure size of B_j)：记录B_j向B_i的z_j的转移矩阵权重W_i,j，包括i=j；
vector<FP32>b(2*neure size of B_i)：偏置bias b_i；
vector<FP32>r(2*neure size of B_i)：类ctm中间计算量；
vector<vector <FP32> >W_c[hold_tick](neure size of B_i)(2*neure size of B_i)：记录将cfc前后两半逐元素乘后的结果转化为a的权重,层归一化用；
vector<FP32>b_c[hold_tick](neure size of B_i)：计算cfc时的偏置bias b_c；
sigma()函数，定义为逐元素x变为(1+e^-x)^-1;
LN()层归一化函数
对于block，一次更新为
如果 B_i 有 readin adapter：
    o = readin_adapter(外部输入)；
没有：o=0；
r = o + b + sum_{j active} W_ij * z_j;
a = LN(r[0 : neure size of B_i] ⊙ sigma(r[neure size of B_i : 2*neure size of B_i]));
t_last = time(0);
if(A.size()==hold_tick)A.pop();
if(At.size()==hold_tick)At.pop();
A.push_back(a);
At.push_back(t_last);
h = vector<FP32>(neure size of B_i, 0);
for idx =  A.size()-1 ..0:
    a_k = A[idx];
    t_k = At[idx];
    delta_t_ms = t_last - t_k;
    t_last=t_k;
    m = [a_k;h];此处指拼接两个向量；
    h_c = W_c[idx] * m + b_c[idx];
    h_c = LN(h_c);
    gamma = sigma(delta_t_ms/ticktime_ms);
    h = (1 - gamma) * h_c + gamma * h;
end for
z_i = h;
关于route：
	route对应的block强制永久激活；
关于readin：
	每个readin都会在有新输入到达时无视route强制激活一次block；
关于所有readout：
	最终产生的操作控制信号，有人控开关，如果关上的话将仅正常输出控制信号到机械日志，但不执行操作，不返回任何状态给core。也就是操作失败只记录机械日志，不告知core；
	即使成功操作，也不会主动返回任何消息（比如操作成功码）给core，毕竟谁家好人自己身体要靠传出神经反向传递消息给大脑的，除了goodness更新用的，那个算内分泌，没招；
关于goodness：
	goodness是一个readout，对应一个且仅对应一个block，记该block为B_g，其adapter为A_g；
	A_g是神经网络；A_g与B_g共同构成goodness readout子系统，其参数同样只采用局部塑性动力学更新；
	B_g不是readin，因此没有readin adapter，o=0；
	B_g按block一次更新规则更新，得到z_g；
	当B_g goodness人控开关开启时：
	g_ = clamp(A_g(z_g), 0, 1)；
	g作为goodness readout的唯一输出，用于训练；
	当B_g goodness人控开关关闭时：
	仅正常输出g到机械日志，不返回任何状态给core；也就是goodness输出失败只记录机械日志，不告知core；
	B_g的active由人工开关控制；
	goodness输出只有一维标量g∈[0,1]；不设并列输出轴；
	定义：
		g = clamp(A_g(z_g), 0, 1)，内部自评输出；
		g* ∈ [0,1]，可选外部好度标签/目标；
		g_eff：有效好度训练标量。同一时刻存在准确g*时，g_eff = g*，即g*覆盖g；否则g_eff = g。除goodness readout子系统自身外，其他block和adapter只把g_eff作为唯一全局塑性调制信号；
	goodness readout子系统不能通过“把自己输出的g变大”来训练，否则会形成自我奖励漏洞；
	当存在外部g*时，定义仅供goodness readout子系统使用的校准标量c_g = g* - g；B_g与A_g只允许利用各自局部活动、自己的local plastic state以及c_g进行校准，使g逐步拟合g*；c_g不发送给其他block/adapter，也不构成第二条全局Goodness；
	当不存在g*时，不对B_g/A_g进行上述teacher校准；此时g可以作为g_eff供其他神经组织使用；
	同一个对象允许g_{t1}(o) ≠ g_{t2}(o)；
	tips:goodness其实就是在实时拟合实现对teacher好度输出散点的连续化和超分辨
关于运行时实时参数塑性训练采用Local Plasticity Dynamics：
	正式ACNT的参数改变靠且仅靠局部塑性动力学；生产运行中不运行e-prop，不维护∂z/∂θ、∂q/∂θ、Jacobian、backward sensitivity、BPTT图或其他全局梯度状态；
	对每个B_i，仍记其可训练参数集合：
		θ_i={W_{i,j} | j∈所有block，含i=j} ∪ {b_i} ∪ {W_{c,i}[k], b_{c,i}[k] | k=0..hold_tick-1} ∪ {adapter_i}；
	其中adapter_i只在B_i对应某readin或某readout时存在；因readin与readout对应不同block，故至多一个；无对应则无adapter；
	每个可塑的局部连接/局部参数单元c维护自己的局部突触痕迹e_c；e_c初值为0，不是e-prop eligibility，也不保存梯度或全局敏感度；
	局部事件发生在真实时刻t时，先按距该连接上次痕迹更新时间的真实时间Δt衰减，再加入仅由该连接自身pre/post局部活动形成的项：
		e_c ← exp(-Δt/τ_e)e_c + F(pre,post)；
	τ_e>0，以秒计；F(pre,post)只允许读取该连接真实存在的局部pre/post活动，不得读取目标、全局误差、Jacobian或其他连接状态；
	对于W_ij：局部pre来自B_j当前z_j，局部post来自B_i真实产生的局部神经活动；
	对于W_c/b_c：只允许读取其所在Block temporal/CfC计算中真实存在的两端局部活动；bias可以视为来自常数1输入的局部连接；
	对于readin/readout adapter：adapter内部每个局部连接同样只读取自己的pre/post活动并形成自己的e_c；adapter不享有额外通道；
	Goodness到达前，即使等待期间没有任何forward或局部事件，也必须先把当前e_c按真实时间衰减到Goodness到达时刻，再进行参数更新；
	除Goodness ReadOut自身B_g/A_g外，全部可塑参数共同维护一个全局近期Goodness内部代谢基线，记为G_bar，初值0.5；
	收到唯一g_eff时，先使用更新前的G_bar计算：
		M = g_eff - G_bar；
	随后所有上述可塑参数统一按各自当前局部痕迹更新：
		Δw_c = η M e_c；
	全部参数完成本次更新之后，才按距上次Goodness的真实时间Δt更新基线：
		G_bar ← λ_G G_bar + (1-λ_G)g_eff；
		λ_G = exp(-Δt/τ_G)，τ_G>0，以秒计；
	G_bar只是唯一Goodness的内部代谢基线，不是第二评价流，不作为新的ReadIn/ReadOut，不向world或Core输出；
	Goodness ReadOut自身B_g/A_g不使用g_eff、M或G_bar进行自我强化；当同刻存在g*时，仍保持原定义c_g=g*-g；
	B_g/A_g只允许用各自局部pre/post活动形成的同样时间化e_c以及c_g进行teacher校准；c_g不发送给其他Block/Adapter，也不是第二条全局Goodness；
	Eye、Ear、Core、Hand、Speak、Route及其Adapter不设器官特例，全部遵守同一“局部突触痕迹 + 全局Goodness神经调制”原则；
	延迟Goodness到达时不回放计算图、不回放过去活动；参数只读取衰减到到达时刻后仍保留的e_c、唯一M及自身w_c；
	当前CorrelationRule保留局部相关活动作为F(pre,post)的第一版实验候选；F的更合适局部形式仍可通过实验比较，但真实时间衰减、M、参数更新顺序与G_bar更新顺序属于正式架构，不是候选项；
	正式ACNT不使用e-prop、梯度、Jacobian、BPTT、backward sensitivity、策略梯度、固定随机反馈或credit assignment；除同刻teacher校准c_g外，整个ACNT只有g_eff这一条全局评价流；
关于e-prop的定位：
	e-prop不再属于正式ACNT架构，不进入生产运行，不作为参数更新机制，也不为生产模型长期保存任何e-prop状态；
	只允许在很小的科学对照系统中作为oracle/benchmark，例如4个Block的toy system中计算较完整的sensitivity，用于测量Local Plasticity Dynamics相对梯度信息丢失了多少、方向一致性如何、任务性能差多少；
	e-prop对照结果只能用于研究、诊断和选择F_e/F_w候选，不能在正式ACNT运行时偷偷给Local Plasticity Dynamics提供梯度、teacher trace或额外credit信号；

关于最终离散控制的随机干扰：
对于所有最终需要形成01离散操作的readout，不直接由adapter输出01；
adapter先输出对应离散操作的连续倾向值，记为q；
对每个离散控制量独立加入随机干扰ε，再经过硬阈值形成最终01操作：
a = 1[q + ε > θ]；
其中a∈{0,1}；
θ为该离散控制量的阈值；
ε为该离散控制量自己的随机干扰，不同离散控制量默认使用独立ε，不共用同一个随机数；
第一版ε采用Logistic分布：
ε ~ Logistic(0, τ)；
其中τ控制随机干扰强度；
因此：
p = P(a=1|q) = sigma((q-θ)/τ)；
也就是说，Bernoulli随机控制仅作为该机制的概率解释，实际统一实现按：
连续神经倾向q + noise ε + hard threshold → 01实际操作；
不额外建立Bernoulli sampler模块；
以后允许修改noise的分布、强度以及时间相关性，但不改变上述“神经倾向 + noise + threshold”的基本离散控制接口；

该随机干扰只用于最终需要形成离散事件的控制量；
对于hand：
	键盘每一个可独立按下/释放的键控制分别独立进行上述随机干扰；
	鼠标左键、右键、中键等离散按键控制分别独立进行上述随机干扰；
	多个键允许同时成立，例如K=1且S=1，因此不使用Softmax，不要求所有离散动作概率和为1；
	鼠标位移等连续控制量不经过该01阈值机制，仍由adapter连续输出；
对于route：
	route adapter对总block上限数个block分别输出一个连续倾向q_i；
	每个block分别具有独立noise ε_i；
	最终：
		active_i = 1[q_i + ε_i > θ_i]；
	所以多个block可以同时激活，也可以同时休眠；
	route block自身永久强制active，不受该随机干扰结果关闭；
对于speak：
	约30维仿生发声器官参数属于连续控制量，不强制经过01随机阈值；
对于goodness：
	g属于连续一维好度值，不经过该随机阈值机制；

随机干扰发生在readout adapter完成神经计算之后、机械操作真正形成之前；
因此：
	block/core内部状态与计算不因为随机探索而直接加入参数噪声；
	随机性只作用于对应的离散控制决策；
	实际world只经历随机干扰后真正发生的那一个动作；
	不假设能够返回同一个world状态尝试另一个动作；
	不要求同时得到正反两个动作的结果；
	整个训练始终沿单条不可逆时间轨迹向前运行；

对于人控开关：
	先正常完成adapter输出、noise干扰和最终控制信号生成；
	若对应readout的人控执行开关关闭，则最终控制信号仅写入机械日志，不真实执行；
	不向core返回“被禁止执行”“执行失败”等状态；
	该规则与原readout规则保持一致；

关于最终离散控制与Local Plasticity Dynamics：
由于最终：
a = 1[q + ε > θ]
为硬离散操作，因此正式ACNT不对a、q、hard threshold或world求导，也不构造∂a/∂q、∂q/∂θ、log-policy gradient或e-prop eligibility；
连续神经倾向q、此次本地noise realization以及最终实际形成的离散事件a，都是该readout终端本地真实发生的信息；它们可以进入本连接的F(pre,post)，但不会作为额外world反馈返回core；
离散控制readout不建立F^ctrl器官特例，其内部连接与Eye/Core/其他Adapter完全使用同一正式接口：
	e_c ← exp(-Δt/τ_e)e_c + F(local_pre,local_post)；
其中local_post允许包含该终端实际形成的q与a等本地输出活动；F仍只能读取本连接局部活动；
当未来唯一g_eff到达时，先把e_c衰减到到达时刻，并用更新前的G_bar计算M=g_eff-G_bar，再统一通过：
	Δw_c = η M e_c；
进行更新；全部参数更新后才按正式公式更新G_bar；
不要求同一world状态重新尝试另一个动作，不要求知道未发生动作的结果，不要求world可微，也不要求离散控制可微；
如果noise造成某个离散动作偶然发生，那么该动作是否能在未来被增强或抑制，只能取决于：
	这次动作前后在局部神经连接中留下了什么e_c；
	之后到达的唯一g_eff；
	衰减后的e_c与唯一M怎样按正式公式修改局部参数；
这里不固定(a-p)/τ、REINFORCE、straight-through estimator或其他policy-gradient公式为正式机制；这些都只能作为实验对照候选；
若一个readout同时具有多个彼此独立的离散控制量，每个控制量仍拥有自己的noise和实际事件a；它们只通过各自涉及的局部连接形成local plastic state，不建立Softmax竞争，也不共享第二个reward；
route与hand都遵守这一规则；route block自身永久强制active这一硬规则不参与学习；
因此当前离散控制训练可以概括为：
	block/readout产生连续神经倾向q；
	noise使唯一现实时间线上偶尔产生不同的离散操作；
	hard threshold产生真实01控制；
	相关局部神经连接仅依据自己真实经历的pre/post/output活动形成时间化局部突触痕迹e_c；
	延迟到达的唯一g_eff先与G_bar形成M，再调制已衰减到该时刻的e_c对应参数变化；
整个过程不存在全局backward sensitivity，不要求DAG，不要求world reset，不要求在同一状态分别尝试两个动作。

关于0阶段：
0阶段其余设计不变；
由于route强制关闭，route不参与随机干扰实验；
goodness强制关闭，因此g仍由外部读取机械日志后提供；
