# ACNT 当前唯一架构规范

本文只定义当前仍成立的 ACNT v0.x 架构，不记录候选演变、实验历史或训练资料计划。

## 1. 总体结构

系统由 ReadIn、Core 与 ReadOut 组成。Core 是固定容量的 Block 集合；Block 可以 active 或 dormant，但不会因休眠被删除。

六个器官必须分别绑定六个不同的 designated Block：

- ReadIn：Eye、Ear。
- ReadOut：Hand、Speak、Goodness、Route。

Eye 接收 1080p 屏幕像素；Ear 接收原始音频。文本若要进入系统，必须先成为允许的感知形式。Hand 产生键盘、鼠标按钮与位移控制；Speak 产生连续发声器官参数；Goodness 产生唯一标量；Route 产生各 Block 的 active/dormant 控制。

ReadIn 的 Adapter 输出写入其 Block 的 o。新 ReadIn 输入强制 designated Block 更新一次，即使 Route 未选中它；Core 调用完成后 o 被消费并清零。Route Block 永久 active。Goodness Block 是否 active 只由人控开关决定，Route 不能覆盖这两个角色约束。

## 2. Block 状态与参数

Block i 定义：

- neuron_size n_i；
- scheduler 间隔与真实时间归一化尺度 ticktime_i，单位 ms；
- 历史长度 hold_tick=M_i；
- committed output z_i in R^(n_i)；
- 当前 pre-activation a_i in R^(n_i)；
- synapse accumulator r_i in R^(2n_i)；
- ReadIn Block 的输入 o_i in R^(2n_i)，其他 Block 视为零；
- 历史 A_i，保存最近 M_i 个 a_i；
- 历史时间 At_i，保存 A_i 每项对应的逻辑时间戳，单位 ms；
- 对每个 source Block j 的 W_ij in R^(2n_i x n_j)；
- synapse bias b_i in R^(2n_i)；
- 每个 neuron 私有的 NLM 参数。

A 与 At oldest-first、一一对应。只有 Block 真正 update 时才追加 (a_i, now_ms)；超过 hold_tick 时 FIFO 删除最旧一对。now_ms 是真实逻辑时间，不是计算耗时。时间不得倒退，失败的 update 不得留下 partial commit。

生产状态与可塑参数均为 FP32。持久状态在 update 后 detach；正式参数更新不建立 autograd graph。

## 3. Snapshot synapse mixing

一次 Core scheduling event 首先抓取所有 active source 的 OLD committed z snapshot。同一事件中的所有 destination 都读取这一个 snapshot；本轮刚计算出的新 z 不会被本轮后访问的 Block 读取。

对 active destination Block i：

r_i = o_i + b_i + sum_(j in active) W_ij z_j

令 r_i 的左右两半各为 n_i 维，则：

a_i = LN(r_i[0:n_i] elementwise_mul sigmoid(r_i[n_i:2n_i]))

LayerNorm 跨本 Block 的 neuron 维执行，无可学习 affine 参数。这一 Linear -> GLU -> LayerNorm 阶段是跨 neuron、跨 Block 的 synapse mixing。不同 neuron_size 的 Block 通过对应形状的 W_ij 连接。

## 4. Per-neuron real-time NLM

跨 neuron mixing 只发生在 synapse stage。时间历史处理只发生在 private NLM；NLM_d 不读取其他 neuron 的历史。

当前时刻 t_now 对历史项 k 的 real-time age 为：

age_k = (t_now - t_k) / ticktime_i

t_now、t_k 与 ticktime_i 都用 ms，因此 age_k 无量纲。age 直接作为输入；不施加裁剪、指数、对数或额外时间变换。ticktime 同时承担 Core scheduler 间隔尺度与 NLM age 归一化尺度。

当当前历史长度 K <= M_i 时，为 neuron d 构造三个长度 M_i 的向量并右对齐真实项：

- activation_d = [a_d^(1), ..., a_d^(K)]；
- age = [age_1, ..., age_K]；
- validity = [1, ..., 1]。

左侧 padding 的 activation、age、validity 都为 0。validity 用于区分真实零 activation 与尚不存在的 slot。Block 内所有 neuron 共享 age 与 validity；activation history 是 neuron-specific；时间戳只在 At 保存一份。

x_d = activation_d concat age concat validity in R^(3M_i)

所有 neuron 用 grouped parameter tensor 并行计算，但数学上等价于独立模型：

u_d = W1_d x_d + b1_d in R^(2H)
q_d = GLU(u_d) in R^H
v_d = W2_d q_d + b2_d in R^2
z_d = GLU(v_d) in R

默认 H=nlm_hidden_dim=4。W1_d、b1_d、W2_d、b2_d 都只属于 neuron d。最终并行得到 z_i in R^(n_i)。

一次真实 BlockRun 的提交顺序为：读取 old snapshot；计算 r；计算 a；形成候选 A/At；构造 NLM 输入；计算全部 z；验证有限性；一次性 commit r、a、z、A、At。

## 5. ReadOut 与机械边界

ReadOut Adapter 只读取其 designated Block 的 committed z。Hand 与 Route 的每个离散坐标由连续倾向 q 加独立 Logistic noise 后与 threshold 比较：

action_k = 1[q_k + noise_k > threshold_k]

各坐标独立，不使用动作间 Softmax 竞争。鼠标位移、Speak 与 Goodness 是连续量。

机械执行开关位于最终信号之后。关闭时仍生成信号并记录机械日志，但不执行外部动作。执行结果与失败不得反馈回 Core。Route 的角色覆盖在采样后执行：Route 自身保持 active，Goodness 保持人控状态，ReadIn 强制更新规则保持有效。

## 6. 唯一 Goodness

Goodness 只有一个标量 g in [0,1]。当同一事件存在准确外部 g* 时，普通连接使用 g_eff=g*；否则在 Goodness 启用时使用 g。不得增加新的 Goodness 轴或全局 credit signal。

Goodness Block 与 Adapter 不用自己的输出自我强化。同刻存在 g* 时，它们只接收局部校准 c_g=g*-g。其他连接只接收唯一 g_eff。

## 7. Local Plasticity Dynamics

每个普通可塑参数元素维护自己的局部 eligibility 状态 e_c：

e_c <- exp(-Delta_t/tau_e) e_c + F(local_pre, local_post)

Goodness 到达时：

M = g_eff - G_bar
Delta_w = eta M e

G_bar 按现有真实时间 EMA 更新。Goodness 子系统的校准沿现有 c_g 路径进行。Local Plasticity 不使用梯度、BPTT、policy gradient 或额外全局反馈。

Dense 参数的局部候选使用真实 linear input/output。bias 将输入视为常数 1。private grouped NLM linear 对 X[n,in]、Y[n,out] 定义：

F_W[d,o,i] = Y[d,o] * X[d,i]
F_b[d,o] = Y[d,o]

这里只允许同一 neuron d 的两端相乘。第一层 local post 是其真实 pre-GLU linear output；GLU 结果是第二层 local pre；第二层 local post 同样是 pre-GLU linear output。不构造 derivative。

Adapter 的 Linear/Conv 与离散 control terminal 继续使用同一局部 observer 框架。当前 CorrelationRule 是可替换的局部候选，不是额外架构轴。
