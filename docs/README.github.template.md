## 发布检查

- 检查待提交的文件清单、单文件大小、总体积和数量；建议普通文件不超过 1 MiB、关键日志不超过 256 KiB、小样本合计不超过 5 MiB。这是项目默认审查阈值，不是 GitHub 平台限制；低于阈值仍需审查内容。
- `.gitignore` 不能判断文件大小，也不会移除已跟踪文件；检查暂存区和已有 Git 历史，避免旧提交携带大文件。
- 不用 `git add -f` 绕过规则上传原始数据；确需小样本时，只添加审查后的精确路径例外。
- 检查凭据、个人信息、机器路径、授权与许可证；报告同样需要脱敏。
- 确认报告状态、来源和结论可核验；未收集的信息写“未核验”，不把模板当成实测结果。
