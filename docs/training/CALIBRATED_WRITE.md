# 自校准向量 Write：从原版前向启动在线训练

2026-10-01。这是用户授权重新设计后的新候选。原版普通 Block 的
GLU、非仿射 LN、有限 History、私有 NLM 前向保持不变；当前实现仍是
七个普通 Block 的同步 toy，不是完整 Runtime 集成。

## 为什么改变信用的分工

先前让一个低维 F 负责从有限状态重新发现每个参数的方向，难以启动。
这里把可从前向直接计算的逐参数信用放进 E，Write 输出独立向量，
负责调制它。活动相同不被当作信用相同，也不依赖共享标量地址函数。

行为信用用原版前向的流式敏感度：

\[
J_{t+1}=A_tJ_t+B_t,
\qquad score_p=\partial_{\theta_p}\log\pi+
\partial_s\log\pi\,J_{:,p}.
\]

J 覆盖所有普通 Block 的 z 和有限 History。固定权重、无裁剪时该
导数是准确的；实际写入后停止更新导数，属于近似。只保留一个事件
的计算图，事件结束后全部 detach，不保存可重放的经历或动作日记。

行为 E 保留指数递推、动作注入、范数限制 10、迹限制 100。
对照采用原时间常数 8/32/128 ms；即时反馈候选采用 .1/.1/.1 ms。
后者基本只保留当前动作，不声称已经解决匿名延迟反馈问题。
时间常数改变是实际算法设置改变，不能表述为“现有 E 完全不变”。

## 用当前 goodness 校准 Write，写入也覆盖它自身

普通 Block 6 接收 `[G,G_valid,own_action,action_valid]` 的 ReadIn 投影。
它的 z 经向量 Write 的独立权重行，一次产生全部 F。没有标签输入，
没有正确动作旁路，未到来的 G 也不会进入当前动作。

注册参数按结构区分两类，不跨张量分组：

- 行为参数：普通 Block 0..5、Ear、Hand。
- 校准参数：普通 Block 6、反馈投影、Write 自身。

两类全部可写，区别在资格信用的定义，不是保护某个区域。
N=4,g=32 时，共 3,756 个实际参数；行为 2,585，校准 1,171。
Write 为 `Linear(4,143)`，有 715 个参数，其中 23 组覆盖它自身。
143 个输出中行为组 102、校准组 41。

行为组输出是 tanh 的有符号信号；校准组用 `(1+tanh)/2` 得到正增益。
设置任务无关的当前校准目标：

\[
y_k=\begin{cases}2G-1,&k\text{是行为组},\\
1/2,&k\text{是校准组},\end{cases}
\qquad L_W=\frac1M\sum_k(F_k-y_k)^2.
\]

程序明确规定这个目标；不是 Core 自己发明了损失，也不是任务标签。
其作用是教 Write 把已经收到的 G 转成行为强化/抑制信号，以及把
自身校准增益保持在中间范围。

资格向量的绑定为：

\[
E_p=\begin{cases}
mean_\tau(trace_{p,\tau}),&p\text{是行为参数},\\
-\partial L_W/\partial\theta_p,&p\text{是校准参数}.
\end{cases}
\]

校准梯度包含当前输出的直接参数项和 `partial_s L_W * J`，所以
普通 Block 6 与反馈投影也能获得校准信用。它不保留原来控制参数的
行为 score 绑定，属于新设计，不应把这一改变藏在“局部钙迹”比喻中。

每个实际参数的学习信号是 `u_p=E_p*F_group[p]`。执行器对 u 做
有限 Adam 风格动量/平方矩预处理，然后一次提交所有实际参数更新。
控制组的正 F 也决定自身校准学习信号。没有外部 optimizer、没有
另一个受保护的 controller、没有独立 origin 参数更新。固定 origin
只作坐标基点，所有生效权重都是 `origin+delta`，delta 覆盖全部参数。

注意：F 调制的是进入动量的信号，最终更新仍受已有动量影响；不能
声称每次实际 delta 都与当前 F 同号，或当前 F=0 一定立即停止旧动量。
这仍需要单独的停止接口设计与验证。

## 尺度与稳定限制

Hand 和 Write 读出的 z 增加因果逐神经元标准化。每次读出使用当前
及过去状态的指数一、二阶矩；固定 2N 大小，不保存样本。均值/尺度
求导停止，最小尺度 1e-3。Adapter 参数数量不变，但输入映射改变。
标准化不是观测者 probe，不用标签拟合，也不冻结实际 Core 参数。

学习率：普通行为参数 .001，Hand .01，校准参数 .003；总更新范数
上限 .02，实际参数范围 [-4,4]；J 范数上限 1,000，记录每次裁剪。
这些限制能约束单次写入和参数值，不保证长期状态或信用一直准确。
rate 是固定算法配置，不是暂时豁免某些参数的写权限。

## 有限数值状态与实验协议

主体保留：Core z/History、实际参数位移、J、指数资格迹、优化矩、
标准化统计和少量计数。J 和优化状态是额外训练数值状态，不冒充
Core H；其中不含逐事件经历表。实验写出的 rows 是观测者日志，
学习器不读取它们。统计字节数恒定检查不等于测量峰值进程内存。

每次决策分四个事件：听到 cue、两次继续前向、输出动作后立即收到
标量 G，再执行反馈前向与自写。动作在当前 G 进入 Core 之前产生。
同一连续轨迹中没有神经状态重置、参数回滚、反事实试行动作或重放。

`core` 是候选。`broadcast` 在执行器直接用 2G-1 替代行为 F，只是
显式教师对照。`cut_calibration` 切断校准参数 E；`no_write` 不写参数；
`no-normalize` 检查新增读出尺度改动的贡献。
switch 世界按 A→B→A 改变 cue 与动作的对应关系；任务阶段不输入主体。
回到 A 后重新适应不等于已保留 A，也不是同时学习多个任务的验证。

## 验证与下一步

全量回归 248 项通过。新增检查验证：给定非零 E/F 时所有实际坐标
包含全部 Write 参数都可变化；实际校准会写入自身；origin 不变；
切断校准阻止对应自写；固定权重流式 J 与原版完整前向展开一致；
资源状态不随轨迹长度增加，事件图不保留。

实验结果与复现入口见
[报告](../../reports/calibrated_write_online_2026-10-01.md) 和
[实验脚本](../../experiments/calibrated_write_online.py)。
先检验多种子条件任务，再检验规则切换；尚未验证匿名延迟反馈、
长期任务保留、真实不可逆行动后果或大规模可用性。
dense J 只是可检查的参考实现，后续需要更便宜的信用传播近似。

## 规则切换后的结构候选

首版完成3,000决策的A→B→A轨迹：A学会，B阶段退回约随机，回到A后
再次恢复。报告保留逐段曲线作为诊断，不能将中间低值直接判为学习失效。
固定1000次后的规则切换可能打断仍在适应的过程。

`calibrated_write_continual.py` 在另一个新生命中测试两项共同改动：
普通行为Core/Ear学习率从 .001 降到 .00001；Hand ReLU 改为
LeakyReLU(.1)，Hand仍 .01、校准参数仍 .003。不增加可训练参数。
希望降低表示变化速度、保持读出的负侧梯度。尚未证明首版的中间低值是
ReLU失活，也不能从这个联合改动的结果单独归因。

所有实际参数仍通过同一执行器可写，慢速Core不等于冻结或保护区域。
该实验没有读取先前轨迹、恢复检查点或重置主体；数值及源码哈希另存。

## 当前 toy 的前向有界条件

可以给一个有限范围的数学保证。设实际权重/偏置绝对值不超过 C，
普通 Block 宽度 N、History 长度 m、NLM 隐藏宽度 h，所有 retained
history 的归一化年龄不超过 D。非仿射 LN 输出满足 |a_i|<=sqrt(N)。
每个私有 NLM 输入的绝对值和最多为 `m*(sqrt(N)+D+1)`，因此两个
Linear/GLU 的线性支路给出：

\[
|hidden_i|\le C m(\sqrt N+D+1)+C,
\]
\[
\boxed{|z_i|\le C h[C m(\sqrt N+D+1)+C]+C.}
\]

sigmoid 门绝对值不超过1，故不会增大该界；下次 r 虽然依赖此前 z，
LN 仍把保留的 a 拉回同一个范围，不需要假设递归边本身是收缩映射。
初始参数也须满足该范围，ReadIn 有界，LN epsilon>0。

当前同步 toy 每2ms更新全部Block，ticktime=1，取保守 D=6，
C=4,N=4,m=3,h=2，得到 |z_i|<=900。这个宽松界只说明在这些条件下
原版前向不会因时间长度而无限增大，不说明实际激活接近900。
参数裁剪、单次更新上限、迹/J裁剪、标准化尺度下限和归一化学习信号
也限制相应数值状态。FP32具体舍入及实现错误仍依赖运行检查。

对真实异步 Runtime，长时间未更新的Block可能出现无上界的history
年龄，故不能直接套用 D=6；需要另行约束或设计年龄输入的处理。
前向数值有界也完全可能行为停在随机，首版B阶段就体现了两者区别。

## 持续探索的另一候选

慢Core/Leaky Hand版在B末段恢复，但回到A后又退化到近乎常量动作。
这是当前截止时观察到的行为，不证明继续学习后仍不能恢复。
这不是数值发散，且F校准仍然正确。为进一步定位动作过度确定的影响，
在第三个新生命中使用当前未获得G的raw logit q，先选择
`T=max(1,abs(q)/3)`，再以 `sigmoid(q/T)` 采样。
两种动作的概率都至少为sigmoid(-3)，约4.74%，代价是正确动作概率
最多约95.26%。只有一个额外温度数值状态，没有新增可训练参数。

score对已经选择的T作条件求导，停止T选择导数。这是显式近似；在
完整映射q→T(q)→动作概率意义下，不能称为精确无偏policy梯度。
它没有访问当前评价或正确动作，测试结果见exploration_v1，不能
因为有探索下限就宣称已解决长期适应或遗忘。

## 用户明确的评价标准：稳定后的最终 goodness

探索期间的低goodness可以为后续学习提供信息，不是直接否决条件。
主要评价充分探索后、基本稳定的末段goodness；中间曲线用于诊断。
此前以阶段截点低值描述“学习失效/适应失败”的结论过早，撤回。

本次原速率/ReLU版本最后500次实际G均值1.000，正确动作概率均值
0.999952；探索版本分别为0.964与0.952574，末五个100次窗口观察到
高值平台；慢Core/Leaky版分别为0.508与0.507991。
这些是有限轨迹末段观察，不是无限时间数学收敛证明。

下一轮协议应让一个规则保持足够长，持续记录实际G的窗口均值、
趋势和波动；观察到稳定后的末段再评分。若预算截止时仍在变化，应
标为尚未观察到稳定结局，而不是宣称学习机制失败。稳定低值也须
如实报告，与中途暂时低值区分。当前每阶段1000次的协议没有做到
自适应等待，因此中间阶段成绩不能当作模型最终可达成绩。
