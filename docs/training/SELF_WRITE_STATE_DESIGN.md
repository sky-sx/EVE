# ACNT：以有限隐状态分析经历并生成自修改

2026-10-01。当前设计，替代 SELF_WRITE_DESIGN.md 中较早的信用引导写入方案。
已实现一个受限的小模型启动训练参考，见
[SELF_WRITE_BOOTSTRAP.md](SELF_WRITE_BOOTSTRAP.md)。一般架构的长期有效性仍未验证。
现有固定延迟账本实验不验证本设计。

当前硬约束还包括：Write 的命令必须精确覆盖所有实际参数，包含自身。
此前只写部分连接/行为偏置的实现不满足要求；最新接口规范见
[FULL_PARAMETER_WRITE.md](FULL_PARAMETER_WRITE.md)。

## 用户要求

Goodness 提供评价，ACNT 自己分析如何修改参数。经历主要存为隐状态 H，
不长期保留自身活动、参数快照、修改和反馈的逐条记录。不要求先由外部
算法产生参数更新方向再交给 Core 选择。额外学习记忆规模不得随运行时长增长。

进一步明确：当前不给主体“日记本”。经历记忆主要驻留在 Core Block 的
内部状态，包括决定下一次如何修改自己的状态。H 是这些内部状态的数学
记号，不是新增一个游离于 Core 的独立记忆库。Write Adapter 接到的仍是
普通 Core Block；连接角色不构成特殊的“学习 Block”类型。

## 前向定义

令 s 为原版 Core 的输出及有界 History，θ 为实际生效的参数，H 表示参与
写入判断的普通 Block 内部状态；H 也可以分布在多个有界 Block 中。
本实验新增普通 Block 来连接 Write Adapter，并未引入特殊学习算子。
采用固定事件顺序：

1. 所有模块读取同一旧状态与参数快照，按原版语义完成事件前向。
2. 流式读取本次活动、局部自观察、已到达的原始 G 和物理时间间隔，更新 H。
3. Write Adapter 根据 H 和可读的当前局部状态生成参数修改。
4. 执行有限值与幅度检查，一次提交；下个事件才使用新参数。

\[
H_{t+1}=C_\phi(H_t,\operatorname{Read}(s_t,\theta_t),G_t,\Delta t),
\qquad \Delta\theta_t=\operatorname{Write}_\phi(H_{t+1},\operatorname{Read}(s_t,\theta_t)),
\qquad \theta_{t+1}=\theta_t+\Delta\theta_t.
\]

无反馈时提供显式有效位，不将缺失 G 伪装为零。实际提交的修改或提交状态
可以作为下次更新 H 的输入；最多保留一个有界待消费槽，消费后覆盖，
不累积修改列表。每个事件都不是必须写参数，控制器可以输出零更新。

H 是由训练得到的流式压缩函数形成的记忆。它可能表示反馈趋势、行为策略、
自身改变的后果或时间关联，但不预先假定这些语义已经存在。原版 NLM 自带
固定长度预激活 History，若复用该机制，其槽数同样固定；不能因长期运行而扩展。

## 不存什么，怎么读

- 当前 θ 就是网络已经占用的参数存储，不再复制完整历史参数。
- 当前活动从当前 Core 状态/局部张量读取，用完释放；不保存完整活动日志。
- 过去经历通过 H 的变化影响未来判断，不保留逐条训练轨迹、反馈关联表。
- 单步参数提案可以暂时占用工作空间，提交后释放；不保存全部 Δθ 序列。
- 各参数组通过局部/流式 Read 接口暴露当前值与结构，可共享读取和写入网络。
  压缩统计可作为输入，但不能把只读统计称为掌握了每个参数的完整信息。

实验日志由旁观评估程序记录，控制器不得读回。调试日志不算作主体拥有的记忆。

## Write Adapter 直接产生更新

第一版允许控制器选择连接矩阵/私有 NLM/行为 Adapter 的注册参数组。
对矩阵组生成门 m、步长 η、向量 u/v，形成固定秩的写入：

\[
\Delta W_g=m_g\eta_g\sum_{r=1}^{R}u_{g,r}v_{g,r}^{\mathsf T}.
\]

偏置组输出有界向量。R 与每次可写组数预先有限，不随经历长度增长。
方向由 ACNT 的 H/当前局部状态生成，不要求候选梯度、真实延迟、目标标签
或正确更新方向作为输入。低秩约束限制单次操作的表达能力，多次写入的
累计表达能力需要实测；有限单步幅度也不等于总体参数漂移受到约束。

评价来源与自己产生的预测分开。控制器不能通过改写评价口提高报告 G。
真正成功必须体现为之后外部反馈改善，并保留已有能力。

## 怎样训练这个前向

学习器参数 φ 仍需要一个明确的启动训练算法。将被写参数 θ 纳入扩大的
运行状态 X=(s,H,θ,有界待消费槽)。固定 φ 时，整个事件定义为 X'=F_φ(X,输入)。
在小模型参考中，可以用流式敏感度：

\[
M_{t+1}=\partial_XF_\phi M_t+\partial_\phi F_\phi.
\]

它包含 H 如何生成写入、写入怎样改变之后神经前向的导数。外部随机动作
的控制器信用从当前策略与 M 计算，之后真实反馈用于训练 φ。
这属于启动训练机制，不是作为分析材料提供给 H 的预制参数更新方向。
不能用“预测自己会成功”代替真实反馈，不能忽略写入路径仍称为完整元信用。

必须区分两类资源：主体经历记忆 H 固定规模；稠密参考训练器的 M 同样
不随时长增长，却可能随参数规模变得巨大。它仅供小模型推导验证，不能
宣称已满足大型 ACNT 的实际内存预算。正式版本还需要压缩训练信用，
并量化其误差。当前已实现受限的稠密参考，尚未实现可扩展训练器。

匿名迟到 G 的启动训练规则也尚需选择与验证。当前基线的匿名迹会退化，
不能直接把同一规则接上本设计便声称学会了反馈归因。若另加监督归因、
已知延迟或离线预训练，必须单独标注改变了哪些实验假设。

## 下一实验必须证明什么

先检查穿过两次写入的短轨迹导数与有限差分一致，只以展开作为测试参照。
随后在连续、不重置轨迹内比较学得 H/Write、冻结 Write、随机 Write、
切断穿过写入的训练信用，以及现有手写更新基线。固定延迟和未知重叠延迟
分别实验，不向控制器提供私有关联。核验 H 与主体附加存储始终固定，
并禁止读取评估日志或重放、回滚世界。

有限 H 不保证保留全部经历，也不保证成为未知世界的充分统计量。
要检验压缩是否保留了影响学习的线索，以及任务变化后是否仍能改进并保留
旧能力。隐状态压缩是本设计机制，其有效性是实验问题。

## 已核对的相关研究（2026-10-01）

- [RL²，2016](https://arxiv.org/pdf/1611.02779)：观察、动作和奖励驱动
  循环状态，学习算法的运行状态存于激活。状态跨同一个 trial 的 episodes
  保留，跨 trials 不保留。这支持隐状态承担学习，但实验有环境重置。
- [Learning to reinforcement learn，2016](https://arxiv.org/pdf/1611.05763)：
  循环动力学学出强化学习过程；新任务开始时重置内部状态，评估时固定
  网络权重。它验证了状态适应，不是运行时主动修改权重的直接验证。
- [SRWM，2022](https://proceedings.mlr.press/v162/irie22b/irie22b.pdf)：
  网络生成 key/query/步长，以结构化写入修改自身权重，包括生成以后
  修改行为的部分。RL 实验使用截断反向训练，记忆在 episode 边界重置。
- [ACL，2025](https://arxiv.org/html/2312.00276v3)：以序列长度无关的内部
  权重状态实现自修改持续学习，无外部重放库。训练目标同时评价新旧任务。
  实验为提供图像标签的有限任务序列，元训练使用 BPTT；任务增多后性能
  仍可能下降，不是标量 G 的无重置不可逆终生学习验证。
- [Learning to Learn without Gradient Descent by Gradient Descent，2017](https://arxiv.org/html/1611.03824v6)：
  循环优化器根据查询与标量结果更新状态、产生下一次查询，无需部署时的
  目标梯度。研究同时测试 LSTM 与带独立记忆的 DNC；当前只考虑 LSTM
  方向。训练长度课程从 10 增至 100，论文明确指出长时训练困难。

这些结果使“有限内部状态能实现学习”成为已有实验证据支持的机制，
不应再当作完全未知的前提。ACNT 尚待验证的是：原版状态和自写接口能否
在标量 G、有限内部存储、长期不重置的不可逆连续轨迹上维持有效学习。
论文中的具体训练假设不能未经验证直接迁移为 ACNT 的能力声明。
