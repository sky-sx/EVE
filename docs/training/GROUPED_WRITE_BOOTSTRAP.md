# E × 分组 F：首轮机制与配比

## 接口纠正：Write 是控制向量 ReadOut

用户随后明确要求 Write 类似 Hand：普通 Block 的 z 经 Adapter 一次输出
整组控制量，每个输出有自己的参数行。共享标量函数按地址反复查询的
81 参数方案不符合这个要求，保留为历史对照，不再当作该设计的主候选。
它的负结果不能用于否定用户提出的向量控制架构。

`IndependentGroupAdapter` 的当前接口仅接收 z，输出
`F=tanh(W_write z+b_write)`；不读取组地址或当前组权重均值。第 k 行
权重和第 k 个偏置对应第 k 个控制输出。它与 Hand 同属向量 ReadOut，
但目前是单层 Linear，Hand 是两层 MLP，并非相同网络。

已有独立版本实验的数值映射保持不变：之前它虽然接收了未使用的地址
和均值实参，实际只计算 z 的向量读出。本次删除这两个实参，并跳过
无用的查询计算；没有重跑行为训练，也没有产生新的学习成功证据。
原始运行源码保存在既有 source_snapshot / source_snapshot_latest 中。

所有输出使用更新前的实际权重产生，再通过固定组映射执行
`delta_theta[p]=eta*E[p]*F[group[p]]`。Write 自身全部参数在映射内。
独立权重行不等于每时刻任意控制向量可达，也不解决尚未验证的在线信用
分配与启动训练问题。

2026-10-01。用户同意尝试分组方向，并提醒 Write 容量、总参数和反馈量
之间的配比。本轮保留指数资格迹的更新形式，比较每参数 F 与分组 F。
所有实际参数都纳入组映射，包括 Write 本身；无外部经历日记。

## 首先排除闲置参数

前一地址实验 Hand 输出 87 维，二元任务只用了第一维。其余输出的 774
个参数无该任务的直接作用。本轮把 Hand 改为一个输出，并复制原第一层
及第一输出行，使初始动作映射完全相同。七个原版普通 Block、Ear、
反馈投影和第七个普通 Block 的 Write 接法不变。

共同的实际参数为：普通 Block 2,912；Ear 40；单输出 Hand 49；G/自身
动作投影 40，共 3,041。共享 Write 增加 81，最终 P=3,122。多个 F 查询
共享同一生成器，不给每个地址增加一组权重。

## 两种容量设置，均包含自覆盖开销

|生成器|Write 参数|全部参数 P|最多每组参数|F 个数|
|---|---:|---:|---:|---:|
|共享地址生成|81|3,122|1|3,122|
|共享地址生成|81|3,122|8|392|
|共享地址生成|81|3,122|32|125|
|各组独立 Linear(4, F)|715|3,756|32|143|

按注册张量内连续坐标分组，不跨张量；末组可小于指定大小。结构元数据
含组地址与成员映射，不是经历数据。矩阵边、偏置、私有 NLM 及全部
Adapter 参数均列入，不能只覆盖普通 W 矩阵。

共享生成器以第七个普通 Block 的 z、组内当前权重均值、固定地址特征
生成 F。它仍是共享函数，并非 125 个独立可训练输出系数。独立版本让
每组拥有四个 z 系数和一个偏置，直接检验更充足的分组输出容量。

独立头的输出数须把它自身参数也算进去。先统计基础张量的组数 A，
再求固定点：

\[
M=A+\lceil4M/g\rceil+\lceil M/g\rceil.
\]

g=32 时 A=120、M=143，头权重 572、偏置 143，合计 715 个实际可写
参数，分成 23 组由其中 23 个输出覆盖。没有无限追加上级 Controller。
当前构造要求 g>4+1；组控制容量的正剩余必须先满足，不能漏算头参数。

## E 的具体绑定及边界

仓库原本有多种 eligibility，不以生理比喻替代定义。本轮选择在线动作
分数资格迹的现有指数规则：

\[
E^{(\tau)}\leftarrow e^{-\Delta t/\tau}E^{(\tau)};
\quad E^{(\tau)}\leftarrow E^{(\tau)}+score;
\quad E=mean_\tau E^{(\tau)}.
\]

三个时间常数仍为 8、32、128 ms；动作分数范数限制 10、每条迹范数
限制 100，与 `DelayedOnlineTrainer` 相同。不同实验共用同一递推。
不保存任何动作/奖励历史槽或参数修改历史。

逐参数 score 并不是任意的新方向码：行为参数的 score 来自原版 Core
流式敏感度 J_H，Hand 的当前直接梯度，以及 sampled action 的 log pi。
J_H=A_H J_H+B_theta；权重改变时停止写入导数。这和原流式参考一样
在固定权重时准确、实际更新时是近似。包含整个 z/History，不只含 z。

Write 本身不直接进入当前 Hand logit，其 score 要通过此前真正的权重
写入获得：使用 address 原型的联合状态敏感度 T，把对应的 Write score
填入其 81/715 个资格迹坐标。因此这是**行为分数＋自写分数的混合资格迹**，
不是已证明正确的全系统终身 eligibility。时间递推不改，增加自身路径
的绑定方式属于本轮新近似；不宣称等同钙离子动力学。

## 实际写入

\[
\Delta\theta_p=\eta E_p F_{\gamma(p)}.
\]

共享的 F 表示沿 E 或反 E；E 有符号，故最终参数增减可以不同。所有 F
使用旧权重快照产生，整组命令生成后再提交。每次修改范数上限 0.02，
实际权重裁剪到 [-4,4]。只在收到 G 时写入，未收到时继续 Core 前向和
资格迹衰减。先输出动作，再获得该动作 G，不输入标签或期望正确率。

F 先取连续 tanh，范围 [-1,1]，尚未硬二值化或打包 FP32 位。
主体经历上下文来自普通 Core 状态；Write 不直接读取观测者梯度或标签。

## 三个调制条件及启动规则

- `core`：F 完全由普通 Core z 和 Write 产生，无直接 G 旁路。
- `anchored`：F=tanh(G-.5+.25*F_core)，显式常规奖励锚点对照。
- `broadcast`：所有组 F=G-.5，统一奖励广播对照。

后两个条件使用直接 G，不能以其结果证明 Core 自己分析出信用。初始
共享头的末层权重为零、偏置 .05；独立头初始小随机权重、偏置 .05。
非零初始写入让资格迹可以通过实际写入给 Write 提供启动信用。

沿用外部 Write bootstrap，只更新其坐标 origin，不能直接更新行为
参数。全部坐标仍是 origin+当前累计位移，Write 可修改其中所有实际
生效值。联合敏感度通过写入路径传播，E 数值作为已观察的训练状态停止
求导，origin 变化和裁剪也使它成为近似；不是完整终身梯度。

## 额外幅度、时间诊断

`grouped_write_rms.py` 保留原始 E 的注入与衰减，但执行器按逐坐标 RMS
转换幅度，再乘 F。它增加两个 P 大小的数值状态，无新增可训练参数。
RMS 更新与外层导数停止求导，初始 nominal eta=.001，与 raw 版 .01
不同。这是幅度/尺度诊断，不是纯粹只改分组的比较。

另以同一 RMS 执行器和 broadcast G，使用 .1/.1/.1 ms 的极短迹，检查
即时奖励场景下混合过去多次动作的影响。改变的是时间常数；它不属于
“保持现有 E 设置”的主候选，必须单独报告，不能把成功归因于分组 F。

## 数据与数值状态配比

每条轨迹 1,000 个二元反馈，4,000 个持续事件，无主体重置、反事实
重放或旧记录读取。共享头每参数约 12.35 次反馈，独立头约 1.40 次。
每个总参数约 0.32/0.27 次反馈。这些只是预算描述，不是样本复杂度
定理；E 本身还提供逐参数的局部信息，不能把一个 G 当作全部信息。

独立头增加容量，也增加训练自由度，相同绝对反馈数并未保持相同的
反馈/Write 参数比。因此负结果不能作为容量假说被否定的证据。增加
独立头、增加训练预算、提高自身信用质量，是不同实验轴。

共享版联合状态/敏感度/优化矩/actor J/E 迹固定为 2,510,008 bytes；
独立版为 12,826,456 bytes；RMS 共享版为 2,534,984 bytes。另有模型
origin、索引、地址、缓冲区与单事件工作空间。未测峰值进程内存。
J 和 T 是额外训练数值状态，不冒充普通 Core H，也不存逐事件经历。

## 生理联系的范围

[Yagishita 等，2014](https://pmc.ncbi.nlm.nih.gov/articles/PMC4225776/)
支持突触活动与随后时间窗口中的多巴胺信号共同影响可塑性。
[Lee 等，2024](https://www.nature.com/articles/s41593-024-01689-1)
研究用特征相关预测误差解释多巴胺信号异质性。
这些支持“局部资格＋区域调制”的研究方向，不证明固定 g 参数组、
该 ACNT 分数 E、二值符号或此启动规则已获得生理或数学验证。

测试覆盖原版已用 Hand 路径不变、组内调制一致、全参数权限及真实自身
资格迹、指数递推、固定权重 actor 导数、条件自写导数、固定资源、RMS
不覆盖原始 E、自覆盖固定点等。结果另见首轮报告。
