# 自修改的硬约束：包括 Write 自身的全参数控制

2026-10-01。用户明确要求：总计 P 个实际生效参数全部可写，包含所有普通
Block、所有 Adapter，以及产生写入的 Write Adapter 自身。不能只写一个区域。
本文件是写入接口规范及结构验证，不是全参数自修改训练已经成功的声明。

后续用户提出了另一种控制语义：保留逐参数 E，以少量分组方向 F 调制
所有参数，包括 Write 自身。它允许组内相关更新，故不要求 F=P。
下文 F=P 仍是独立连续控制的强基线，不再作为所有候选方案的强制要求。
分组、符号和位编码的核算见 [GROUPED_DIRECTION_WRITE.md](GROUPED_DIRECTION_WRITE.md)。

## 旧原型的确不满足

以 width=4、hold=3、NLM hidden=2 的原型核算新增参数：

| 新增部分 | 参数数 | 目前谁更新 |
|---|---:|---|
| 接有 Write 的普通 Block | 416 | 手写外层启动规则 |
| 动作/G 的输入投影 | 40 | 手写外层启动规则 |
| Write Adapter | 70 | 手写外层启动规则 |
| 原有六个 Block 到新增来源的连接槽 | 192 | 固定为零，不更新 |
| 合计 | 718 | 其中 526 外层可训练 |

旧 Write 输出 14 个标量：u 的 8 个、v 的 4 个、偏置项 1 个、门 1 个。
只写原有 8×4 连接和一个 Hand 偏置，共 33 个参数。矩阵写入还受低秩
结构约束，不能逐坐标独立控制 32 个元素。上述新增参数均不在旧 Write
的写入权限内，Write 也不能修改自身。因此旧原型仅为局部写入基线。

## 单事件精确独立控制的维数

若控制映射为 Δθ=D(F)，控制变量数为 F，参数数为 P，且 D 是普通连续
可微映射，则 rank(∂D/∂F)≤F。要求所有 P 个坐标局部独立可控，必须 F≥P。
F<P 的低秩解码器不能宣称单事件任意 P 维更新。分时寻址可以覆盖全部
参数，但那是跨多个事件的控制能力，应单独说明。

当前采用最强接口要求：每个写入事件产生 P 个标量命令，对应所有 P 个
参数，固定的无参数执行器做 θ_new[i]=θ_old[i]+F[i]。其命令 Jacobian 为 I_P。
它不产生更新方向，不再引入一个也需纳入覆盖的可训练解码器。

## 输出 P 个命令，不必增加 P 个输出单元的权重

使用同一个小型共享 Write Adapter，逐局部参数/小块调用：

\[
F_i=g_\theta(H,\theta_i,\mathrm{address}_i),\qquad i=1,...,P.
\]

所有标量输出合成一个 P 维命令。参数位置是固定模型结构信息，不是经历
账本，也不使用每个参数一个新增的可训练 embedding。生成器参数数不
依赖 P；其自身权重和偏置也注册进同一 P 中。先完整构建模型和 Adapter，
再枚举所有参数，避免“加输出头 → 多出未覆盖参数”的递归遗漏。

必须区分：固定执行器的逐坐标可控性，与生成器是否有能力/是否已经学会
产生所需命令。共享生成没有自动证明任意 H 都能生成任意更新向量；本
参考只验证覆盖和写入语义，不以接口满秩冒充学习能力。

## 同一旧快照产生全部写入

用旧参数完成 Core 前向并得到 H；旧 Write 参数生成所有命令，包括写给
自身的命令；检查全部提案；一次提交全部参数；下一事件使用新参数。
生成命令时不允许一边改 Write 参数，一边用新参数计算剩余命令。
普通 Block 的 z/History 不回算、不清空。注册表若改变必须重建，不能
静默忽略后来增加的参数。

## 谁训练 Write

旧原型的 70 个 Write 参数由 SelfWriteLearner.learn 的手写外层规则训练，
与它直接写给行为参数的命令是两条不同路径。这是启动规则，不能称为
整个系统已经通过 Write 完成自我训练。

新的覆盖接口让 Write 参数自身也成为可写状态，取消永久只读的控制器
区域，但工具权限不会自动教会使用工具。完整训练仍须把所有实际生效
参数纳入状态 X=(Core状态,θ)，推导穿过包含自写在内的转移导数，再确定
利用真实 G 的启动训练原则。当前尚未实现、验证这个全参数训练机制。
不能通过继续新增不受 Write 控制的学习网络来回避此问题。

## 已实现的接口参考与边界

[full_write.py](../../acnt/full_write.py) 提供 SharedWriteAdapter 和无参数的
FullParameterWriteSurface。枚举所有唯一注册 Parameter，包括
requires_grad=False 的参数和生成器自身。不自动用于旧 self_write 核，
因为那个核的部分实际权重在联合状态向量中覆盖注册参数；它需要新的
统一状态/前向集成。该参考适用于实际权重就是注册 Parameter 的模型。

结构测试使用一个普通原版 Block（80 参数）和共享 Write（65 参数）：
总 P=145、总命令维数 F=145。共享生成器每次局部输出 1 个标量，重复
145 个地址完成一个全局写入事件；没有增加 145 个独立输出单元。
测试覆盖所有坐标，包括 Write 输出层自己；验证命令 Jacobian 是 I，
全部命令先算后提交，以及出现新参数时拒绝不完整注册表。

参考会暂存 P 个命令和提案，属于单事件工作空间，不是经历存储；仍须
计入资源预算。主体经历继续主要存在普通 Core Block 状态中。
