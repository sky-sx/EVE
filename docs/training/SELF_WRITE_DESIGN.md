# ACNT 自修改 Block / Adapter：下一版训练架构设计

2026-10-01。响应用户提出的“像 Route 一样给 Core 一个修改自身参数的器官”。
**设计状态：尚未实现、尚未实验。** 原版在线信用实验不等于本架构的验证。

**设计修订：** 用户进一步明确：更新方向应由 ACNT 自己产生，经历应主要
压缩进固定规模隐状态，不依赖长期保留活动、修改、反馈的逐条账本。
当前采用 [SELF_WRITE_STATE_DESIGN.md](SELF_WRITE_STATE_DESIGN.md)。
下文保留的是较早的信用引导方案，作为设计历史与实验对照，不能视作最新版。

## 1. 信息从哪里来

标量 Goodness 确实不直接给出每个参数的更新方向。但它可以和高维的
动作信用向量结合：奖励提供评价，前向敏感度和行动历史提供方向结构。
一个标量反馈不足以唯一辨认任意多维参数改动的因果效果，不等于标量
奖励不能在多次交互中训练很多参数。增加 Block 增加表示和推断能力，
不会凭空增加世界反馈中的可辨识信息。

当前 G 减 EMA 只是方差控制，不是对事件原因的分析。Core 原先也不
直接知道参数值、敏感度、历史更新、尚未归因的反馈；需要显式的自观察输入。
即使这些都可读，知道自身前向结构仍不等于知道未知世界会怎样响应。

## 2. 三种新增功能

**LearningReadIn** 提供当前可获得的自观察，按参数组流式读取：
原始已到达 G、时间和已有反馈上下文；组内参数统计；局部前向敏感度/
动作信用统计；多时间尺度信用迹；过去写入大小与方向；已有 Goodness
预测及其误差。模型预测和真实反馈分开保留。环境私有标签、未来 G、
模拟器私有动作关联一律不能作为输入。

**接有 Write Adapter 的普通 Block** 使用原版 Block 的 History/NLM 机制，保持反馈分析状态，
学习选择可信的历史信用、更新时间尺度和写入目标。多个 Block 可以分别
处理时间归因、参数组选择和写入幅度；初版只用一个，避免多模块无法归因。

**Write Adapter** 是具有实际写入效果的 ReadOut。按注册参数组操作，
第一版允许读/写连接矩阵、私有 NLM 参数和行为 Adapter 参数。
不将直接提高 Goodness 输出值作为成功，也不允许通过写评价口篡改目标。
初版控制器自身参数由下面的启动规则训练；以后才测试自写控制器参数。

## 3. 第一版具体写什么

对参数组 g，维护可供选择的 K 个候选信用方向 c[g,k]。
这些是当前已有的数值方向，可来自可匹配的旧动作信用、多时间尺度匿名迹，
或明确声明假设的预测器；不能称为真实因果梯度。
普通 Block 输出，Write Adapter 解码：

- 写入门 m[g] ∈ [0,1]：选哪些参数组；
- 步长 η[g] ∈ [0,ηmax]：每组改多少；
- 权重 α[g,k]：怎样组合不同历史时间尺度的信用；
- 正对角预条件 p[g]：组内哪些坐标更敏感。

\[
d_g=p_g\odot\sum_k\operatorname{softmax}(\alpha_g)_k c_{g,k},
\quad \Delta\theta_g=\eta_gm_g\frac{d_g}{\sqrt{1+\|d_g\|^2}},
\quad \theta_{g,t+1}=\theta_{g,t}+\Delta\theta_g.
\]

门可以输出近零以暂缓写入。以上光滑界限允许准确局部求导。
现有候选方向提供坐标级结构，控制器起初学习归因与分配，降低任意写入
数千坐标的搜索难度。后续版本才增加有符号混合、矩阵低秩自由方向 U Vᵀ
和偏置自由方向，检验是否真的超过信用引导写入，避免把任意方向称为已学会。

顺序固定：读取旧快照 → 原版神经前向 → 动作或接收反馈 → 形成写入
提案 → 检查有限值/单次幅度 → 一次提交 → 下个事件使用新参数。
写入不会重新计算过去 History，不回滚世界，不重置过去状态。
所有参数组读取同一旧权重快照，不能因组遍历顺序而偷偷串行读取新权重。

## 4. 学习控制器自己怎么训练：把被写参数也作为状态

设被写参数为 θ，控制器可训练参数为 φ，控制器记忆为 h，
信用/基线/预测器等学习状态为 L。整个系统的运行状态扩大成：

\[
X_t=(s_t,\theta_t,h_t,L_t),\qquad X_{t+1}=\mathcal F_\phi(X_t,o_t,G_t,a_t).
\]

这就让“学习”成为下一次前向的状态转移。尤其 θ 不再被当作每个事件
外部替换、求导时忽略其来源的常量。

用固定 φ 的稠密小模型作为导数参考，携带：

\[
M_{t+1}=\partial_X\mathcal F_\phi M_t+\partial_\phi\mathcal F_\phi.
\]

θ 的对应行是 ∂θ/∂φ，明确包括“过去一次写入 → 新权重 → 后来行为”的路径。
当前原版训练器的 J 不含这条更新元梯度；不能直接复用其成功宣称
本架构已经训练。数学定义保持连续的信用运算；若候选方向含导数，
求完整 M 会涉及导数的导数。参考实现必须处理这些高阶项，或者明确
标注冻结候选方向的近似，绝不能偷偷 detach 后继续称为完整元梯度。

对一次真实外部随机动作，保存控制器信用：

\[
e_t^\phi=\partial_\phi\log\pi(a_t|X_t)
 +(\partial_X\log\pi(a_t|X_t))M_t.
\]

迟到 Goodness 更新 φ 的启动规则仍为一个明确的小步在线策略梯度规则。
φ 的好坏由它引起的**后续外部行为的真实反馈**评价，
不会用“自己预测自己的更新有用”代替验证。未作用于未来行为的最近写入
不应被当前反馈当作已经成功的原因。

固定 φ、观测和已实现的动作/路由下，M 是条件神经轨迹准确切线；世界
通过随机动作的 likelihood-ratio 信用进入，不对不可微真实环境硬求导。
若写入目标用离散抽样而不是连续门，它也是动作，必须记录其自身
log-probability 信用，不能对离散选择使用伪造的普通导数。

学习 φ 以后，同样需要说明停止外部更新导数的近似；真正同时把 φ 自写
也放入 X 是进一步的设计。无需先建无限多个“训练训练器”，但必须有一个
明确的启动更新原则、初始程序和写入语义。接口本身不会自发学会使用工具。

## 5. 平均值之后应分析什么

允许一个预测头基于动作前可用状态预测未来反馈/其延迟分布，使用实际
到达后的预测误差训练。误差、预测可信度和真实 G 均给接有 Write 的普通 Block。
一个值预测器只解释“比预计好多少”，本身还不能辨认哪个过去动作造成反馈。
未知延迟时可对候选历史输出归因权重；其因果可辨识性须依赖可观测上下文、
时间结构或探索，而非因为权重归一化就成立。

实验中的世界不给动作关联，当前匿名迹会退化。新架构可以学习更好的
估计和策略，但没有信息时不能恢复任意隐藏的因果关系；这一失败边界要保留。

## 6. 可证伪的下一轮实验

1. 固定 φ，对短连续轨迹比较完整展开、流式 M 与有限差分，覆盖至少两次
   参数写入、权重参与后续行为、控制器状态保留；刻意 detach 写入的错误
   对照应无法通过。此处展开仅作为测试参照，不作为运行训练机制。
2. 在已知固定延迟的同一个世界，用同一计算预算比较现有手写更新、可训练
   Write、冻结 Write、随机 Write；再切断穿过写入的 M，判断“学习如何学习”
   是否真的有作用。所有实验不重置状态，不读取未来，不回滚或重放世界。
3. 增加延迟漂移、匿名重叠反馈和任务规律变化，分析末段表现、遗忘、写入
   强度与归因错误。固定延迟成功与未知延迟成功分别报告。
4. 单一终生轨迹内交替检查旧规律和新规律；只有新规律学习加速且旧能力
   仍保留，才能推进到持续学习主张。真实不可逆损失另建世界协议。

## 7. 与已有研究的关系

用网络输出控制更新规则，与 learned optimizers 接近：
[Andrychowicz et al. 2016](https://arxiv.org/abs/1606.04474)。
学习训练/回报规则参数，与在线 meta-gradient 思路有关：
[Xu et al. 2018](https://arxiv.org/abs/1805.09801)。
动态权重乃至自写权重有直接先例：
[Irie et al. 2022, SRWM](https://proceedings.mlr.press/v162/irie22b.html)。
这些研究支持架构方向值得试，不能当作本 ACNT 在不可逆在线轨迹上
已稳定成功的证据。本设计选择原版 ACNT 状态与一次提交的写入语义，
从小模型的前向元敏感度参考开始，尚未解决稠密元状态规模问题。
